Three checks

Three ways a repo drifts away from the truth

Each check runs live against any public repo, and each one has a deep pass by IBM Bob behind it.

LIES

Docs vs code

Finds the places where the README and contributing guide say one thing and the code does another: script names, ports, Node versions, routes and paths.

How it works

Instant live checks, and a deep pass by IBM Bob

Live · in your browser

Seconds, on any public repo

Fast, deterministic checks that talk straight to GitHub and npm from your browser.

  • No signup, no install, nothing stored
  • No AI: plain rules, and every finding shows the file and line it came from
  • Honest about limits: if it can't check something, it says so

Deep · IBM Bob 2.0

The whole repo, verified

Bob ran each check as its own task on patient/, a sample invoice API with planted problems.

  • Reads the code and the docs together, with full-repo context
  • Ask → Plan → Agent, with parallel subagents
  • Proves a problem before claiming it: a red test, a real Express 5 crash
