This folder contains screenshots from IBM Bob 2.0 task sessions used during the TriRepo hackathon.

|------|------|-------------|

## How to capture

After each Bob session:
1. Take a full-page screenshot of the Bob task session showing the summary
2. Name it according to the index above
3. Place it in this folder

## Why this matters

Each screenshot proves that IBM Bob 2.0 performed the analysis, not a human.
The task session summary shows Bob's reasoning, tool calls, and file edits.
